🔐 Publication officielle

Distinct des versions ci-dessus. Cette section génère un fichier pool-etat.json — toujours le même nom — que vous déposez ensuite sur GitHub Pages, au même endroit que ce fichier HTML. À chaque chargement de l'outil, il essaiera automatiquement de lire ce fichier pour afficher l'état le plus à jour à tout le monde, sans qu'aucun DG n'ait besoin d'importer quoi que ce soit manuellement.

⚠️ Ceci reste un outil autonome sans vrai serveur : le mot de passe est une protection légère contre les publications accidentelles, pas une sécurité forte — n'importe qui inspectant le code source pourrait le contourner. Suffisant pour un groupe d'amis, pas pour des données sensibles.
